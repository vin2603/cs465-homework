# HW3 - Full Stack Frameworks and Libraries

## React Tutorial

Location: hw3/react-tutorial

To run:
cd hw3/react-tutorial
npm install
npm start

App runs at: http://localhost:3000

## Socket.IO Chat Application

Location: hw3/socketio

To run:
cd hw3/socketio
npm install
node index.js

Open browser:
http://localhost:3000

Open multiple tabs to test real-time messaging.
